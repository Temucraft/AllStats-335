# All Stats (3.3.5)

All Stats 1.1 for World of Warcraft 3.3.5a (Interface 30300): shows every stat from the dropdowns next to the
character window (melee, ranged, spell, defense) at once, instead of one group at a time.

- Author: **Ganoran**. Licence: GNU General Public License version 3 (`LICENSE`, and the author's own copy in
  `AllStats/COPYING.rtf`).
- Source of this copy: the `AllStats.zip` kept in the 3.3.5a addon list
  [NoM0Re/WoW-3.3.5a-Addons](https://github.com/NoM0Re/WoW-3.3.5a-Addons) (`src/Addons`).
- Unchanged: the files are exactly as in that zip. This repository only adds this README and the licence file at the
  root, so the Temucraft launcher can install it from Git.

Install by hand: copy the `AllStats` folder to `Interface\AddOns`.
